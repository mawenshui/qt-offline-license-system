# 批量授权输入格式

## CSV

UTF-8。字段：

```text
row_id,customer_id,customer_name,order_id,product_id,license_mode,expires_at,max_runtime_seconds,binding_mode,minimum,features,cpu,board,system_uuid,disk,output_name
```

- `license_mode`：`perpetual`、`fixed_expiry`、`validity_duration`、`runtime_quota`、`hybrid`。
- `expires_at`：带 `Z` 或明确时区偏移的 ISO 8601；永久、签发后有效时长、实际运行时长授权留空。
- `max_runtime_seconds`：`validity_duration` 表示从签发时刻开始的有效秒数；`runtime_quota` 和 `hybrid` 表示应用实际运行额度。
- `features`：用 `|` 分隔。
- `binding_mode`：`all`、`any`、`threshold`。
- CPU、主板、系统 UUID、硬盘至少填写一项。
- `output_name`：仅允许字母、数字、点、下划线、连字符，且以 `.qtlic` 结尾。

整批永久授权样例见 `examples/batch-perpetual.csv`。

## JSON

```json
{
  "schema": "qt-license-batch",
  "version": 1,
  "defaults": {
    "product_id": "ProductId",
    "license_mode": "perpetual",
    "binding_mode": "all",
    "features": ["basic"]
  },
  "records": [
    {
      "row_id": "1",
      "customer_id": "C001",
      "customer_name": "示例客户",
      "hardware": [
        {"slot": "board", "type": "board", "values": ["BOARD-SERIAL"]},
        {"slot": "system-disk", "type": "disk", "values": ["DISK-SERIAL"]}
      ],
      "output_name": "C001.qtlic"
    }
  ]
}
```

`hardware` 中每个槽位只能用 `values` 或 `hashes` 之一。`hashes` 必须是采集端生成的 `sha256:` 格式值。批次先全量预检，再写临时目录，全部成功后原子发布；输出目录已存在时拒绝覆盖。结果包含逐文件 SHA-256 和签名的 `batch-manifest.json`。

批量授权使用载荷 `version: 1`，目标 Runtime SDK 必须为 `1.x`。签发器在开始批次前显示输入文件、输出目录和目标 Runtime 摘要；确认后仍先全量预检，任何一条失败都不会发布部分批次。
